୧. Super Admin Login ଓ MFA

  1. Super Admin website ଖୋଲନ୍ତୁ।
  2. Owner account ର Email ଓ Password ଦିଅନ୍ତୁ।
  3. Sign in securely ଦବାନ୍ତୁ।
  4. Authenticator App ଖୋଲି ବର୍ତ୍ତମାନର ୬ ଅଙ୍କର Code ଦିଅନ୍ତୁ।
  5. Verify code and open Owner dashboard ଦବାନ୍ତୁ। Code ପ୍ରାୟ ୩୦ ସେକେଣ୍ଡରେ ବଦଳେ।
ଅତ୍ୟନ୍ତ ଜରୁରୀ: Password, QR Code, Setup Key, Recovery Code କିମ୍ବା ୬ ଅଙ୍କର OTP କାହାକୁ ଦିଅନ୍ତୁ ନାହିଁ। ଅଜଣା Login request ଅନୁମୋଦନ କରନ୍ତୁ ନାହିଁ। Password reset କଲେ MFA ବନ୍ଦ ହୁଏ ନାହିଁ।

Code ଭୁଲ୍ ଦେଖାଇଲେ ମୋବାଇଲର Date ଓ Time କୁ Automatic କରନ୍ତୁ ଏବଂ ପୂର୍ବରୁ ଯୋଡ଼ା ଥିବା ସେହି Authenticator account ବ୍ୟବହାର କରନ୍ତୁ। Authenticator ହରାଇଲେ ପୃଷ୍ଠାର Recovery ନିର୍ଦ୍ଦେଶ ଅନୁସରଣ କରି Project Administrator ଙ୍କୁ ଯୋଗାଯୋଗ କରନ୍ତୁ।

୨. Owner Command Center ଓ Dashboard

MFA ସଫଳ ହେଲେ Dashboard ଖୋଲିବ। Command Center ର Tile ଗୁଡ଼ିକ ହେଉଛି Shortcut। ଯେଉଁ Tile ଦବାଇବେ, ସେହି Control Section କୁ ନେଇଯିବ।

Dashboard ରେ Customer, Shopkeeper, Shop, Product, Order, Verified Payment ଓ Subscription ର ସଂଖ୍ୟା ଦେଖାଯାଏ। ଏଗୁଡ଼ିକ କେବଳ Summary; ଏଠାରୁ ସିଧାସଳଖ Record edit ହୁଏ ନାହିଁ।

Refresh: ମୁଖ୍ୟ Summary ଓ କିଛି ତାଲିକା ପୁଣି Load କରେ। ଗୋଟିଏ Section ପାଇଁ ସେହି Section ର Refresh Button ବ୍ୟବହାର କରନ୍ତୁ।

୩. Shop Approval, Status ଓ Business Category

Shop Approval & Status

  1. Shop approval & status Section କୁ ଯାଆନ୍ତୁ।
  2. Filter by business type ରୁ Grocery, Hotel ଇତ୍ୟାଦି ବାଛନ୍ତୁ କିମ୍ବା All business types ରଖନ୍ତୁ।
  3. Shop Card ର ନାମ ଓ ବର୍ତ୍ତମାନ Status ଭଲଭାବେ ଯାଞ୍ଚ କରନ୍ତୁ।
  4. Card ରେ ଯେଉଁ Action ଦେଖାଯାଉଛି, ଆବଶ୍ୟକ ହେଲେ Confirmation ପଢ଼ି ତାହାକୁ ଦବାନ୍ତୁ।
  5. Refresh shops ଦବାଇ ତାଲିକା ପୁଣି Load କରନ୍ତୁ।

Category-wise Business Control

Search all businesses / stores ରେ Shop Name, City, Phone, Category କିମ୍ବା Status ଲେଖି ଖୋଜନ୍ତୁ। Category Button ଦ୍ୱାରା ନିର୍ଦ୍ଦିଷ୍ଟ Business ଦେଖନ୍ତୁ। Refresh all ଦବାଇ ତାଲିକା Update କରନ୍ତୁ। ୧୧ଟି Category ହେଲା: Grocery, Daily Needs, Garments, Jewellery, Restaurant, Hotel, Office / Company, Electronics, Medical, Digital Services ଓ Other।

Shop କୁ Approve, Activate, Deactivate କିମ୍ବା Suspend କରିବା ପୂର୍ବରୁ Shop ର ପରିଚୟ ଓ କାରଣ ଯାଞ୍ଚ କରନ୍ତୁ। ଏହା Shop ର Access ଉପରେ ପ୍ରଭାବ ପକାଏ।

୪. Shopkeeper ଓ Customer Directory

Shopkeeper Contact Directory

  1. Directory ଖୋଲନ୍ତୁ।
  2. Search Box ରେ ନାମ, Mobile, Shop Name, City କିମ୍ବା Address ଲେଖନ୍ତୁ।
  3. ମିଳିଥିବା Shopkeeper ଓ Shop Details ଯାଞ୍ଚ କରନ୍ତୁ।
  4. ଯଥାର୍ଥ Business କାରଣ ଥିଲେ Call କିମ୍ବା WhatsApp Link ବ୍ୟବହାର କରନ୍ତୁ। Map Link ଦ୍ୱାରା Shop Location ଚିହ୍ନଟ କରିପାରିବେ।
  5. Card ରେ ଥିବା Account Control ବ୍ୟବହାର କରିବା ପୂର୍ବରୁ Account ଯାଞ୍ଚ କରନ୍ତୁ।
  6. Refresh directory ଦବାଇ ତାଲିକା Update କରନ୍ତୁ।

Database ରେ ଯେତିକି Phone, Address ଓ GPS ତଥ୍ୟ ରହିଛି, ସେତିକି ମାତ୍ର ଦେଖାଯିବ। ଖାଲି ତଥ୍ୟ ନିଜେ ତିଆରି ହେବ ନାହିଁ।

Customer Directory

Customer Name କିମ୍ବା Account Status ଦ୍ୱାରା ଖୋଜନ୍ତୁ। ଏହା Read-only ଏବଂ Privacy ସୁରକ୍ଷିତ ତାଲିକା। ଏଠାରେ Customer ଙ୍କ Private Contact Details ଦେଖାଯାଏ ନାହିଁ ଓ Account Edit କରିହେବ ନାହିଁ। Refresh customers ଦବାଇ ପୁଣି Load କରନ୍ତୁ।

୫. Orders, Products ଓ Catalog

Global Order Console

Order Number, Shop, Customer କିମ୍ବା Status ଲେଖି Load ହୋଇଥିବା Order ଖୋଜନ୍ତୁ। Refresh orders ଦବାଇ ନୂଆ ତଥ୍ୟ Load କରନ୍ତୁ। ଏହି Console Read-only; ଏଠାରୁ Order Status ବଦଳାଯାଏ ନାହିଁ।

Global Product Console

Load ହୋଇଥିବା Product ଓ Stock ତଥ୍ୟ ଖୋଜନ୍ତୁ। Refresh Button ଦବାଇ Update କରନ୍ତୁ। ଏହା Read-only; Product Delete, Edit କିମ୍ବା Bulk Change କରେ ନାହିଁ।

Catalog Management

  1. ନୂଆ Product Category ପାଇଁ Category Name ଲେଖି Add category ଦବାନ୍ତୁ।
  2. Subcategory ପାଇଁ Parent Category ବାଛନ୍ତୁ, ନାମ ଲେଖନ୍ତୁ ଏବଂ Add subcategory ଦବାନ୍ତୁ।
  3. କାମ ସରିଲେ Refresh catalog ଦବାଇ ଯାଞ୍ଚ କରନ୍ତୁ।

ସଠିକ୍ ନାମ ଦିଅନ୍ତୁ। Live Store ରେ ପରୀକ୍ଷା କରିବା ପାଇଁ ଅନାବଶ୍ୟକ Category ତିଆରି କରନ୍ତୁ ନାହିଁ।

୬. Payments ଓ Subscriptions

ଏହି Section ରେ Payment Record, Gateway ଓ Status ଦେଖାଯାଏ। କେବଳ “Success” ଲେଖା ଥିଲେ ଟଙ୍କା Verify ହୋଇଛି ବୋଲି ଧରନ୍ତୁ ନାହିଁ।

  1. Payment Record ର Amount, Gateway, Status ଓ ଯୋଡ଼ା ଥିବା Order / Subscription ଯାଞ୍ଚ କରନ୍ତୁ।
  2. Record “successful but not verified” ଥିଲେ ଏବଂ ସବୁ Reference ଠିକ୍ ଥିଲେ ମାତ୍ର Verify & apply payment Button ବ୍ୟବହାର କରନ୍ତୁ।
  3. Confirmation ପଢ଼ି ନିଶ୍ଚିତ କରନ୍ତୁ। Server Verification ପରେ ସମ୍ପର୍କିତ ତଥ୍ୟ Update ହେବ।
  4. ଆବଶ୍ୟକ ହେଲେ Refresh payments ଦବାନ୍ତୁ।
Pending, Failed କିମ୍ବା ଅଜଣା Transaction ରେ ଏହି Button ବ୍ୟବହାର କରନ୍ତୁ ନାହିଁ। କାହାଠାରୁ UPI PIN କିମ୍ବା OTP ମାଗନ୍ତୁ ନାହିଁ। Payment କୁ ନିଜେ “Received” ବୋଲି ଘୋଷଣା କରନ୍ତୁ ନାହିଁ।

୭. Security ଓ Audit Activity

Security & audit activity ଖୋଲି Admin/Security କାର୍ଯ୍ୟର Record ଦେଖନ୍ତୁ। ବର୍ତ୍ତମାନର Query ଅନୁସାରେ ସର୍ବାଧିକ ସମ୍ପ୍ରତିକ ୧୦୦ଟି Event ଦେଖାଯାଇପାରେ। ଏଥିରେ Action, Entity, Time ଓ ଉପଲବ୍ଧ ଥିଲେ Before/After Data ଥାଏ।

  • Refresh audit logs: Audit ତାଲିକା ପୁଣି Load କରେ।
  • Live audit alerts: Live Connection ଚାଲୁ ଥିଲେ ନୂଆ Event ଆସିଲେ ତାଲିକା Update ହୁଏ।
  • ସନ୍ଦେହଜନକ ପରିବର୍ତ୍ତନ ଯାଞ୍ଚ ପାଇଁ Audit ବ୍ୟବହାର କରନ୍ତୁ। Record ନଥିଲେ କିଛି ଘଟିନାହିଁ ବୋଲି ପ୍ରମାଣ ହୁଏ ନାହିଁ।

୮. All-in-One Control Search

  1. Dashboard ଖୋଲିବା ପରେ ଉପରେ ଥିବା All-in-One Control ଦବାନ୍ତୁ। Keyboard ଥିଲେ Ctrl + K ମଧ୍ୟ ଦବାଇପାରିବେ।
  2. Category Filter ରୁ All, Businesses, Shopkeepers, Customers, Orders, Products/stock, Payments/subscriptions, Security/audit କିମ୍ବା Pages/tools/settings ବାଛନ୍ତୁ।
  3. Shop Name, Phone, Order Number, Payment କିମ୍ବା “catalog” ଭଳି ଛୋଟ ଶବ୍ଦ ଲେଖନ୍ତୁ।
  4. Result ଦବାଇ ସମ୍ପର୍କିତ Section କିମ୍ବା Load ହୋଇଥିବା Record କୁ ଯାଆନ୍ତୁ। ବନ୍ଦ କରିବାକୁ Escape କିମ୍ବା Close Button ଦବାନ୍ତୁ।
ଏହି Search ବର୍ତ୍ତମାନ Dashboard ରେ Load ହୋଇଥିବା Record ଓ ଦେଖାଯାଉଥିବା Control ଖୋଜେ। ସମସ୍ତ ପୁରୁଣା Database Record କିମ୍ବା Private Data ଖୋଜେ ନାହିଁ।

୯. ସୁରକ୍ଷିତ ଭାବେ ବ୍ୟବହାର କରିବାର ନିୟମ

  • ନିଜର ବିଶ୍ୱସ୍ତ ଓ Update ହୋଇଥିବା Mobile/Computer ବ୍ୟବହାର କରନ୍ତୁ। Screen Lock ରଖନ୍ତୁ।
  • ଆବଶ୍ୟକ ହେଲେ MFA ସମ୍ପୂର୍ଣ୍ଣ କରନ୍ତୁ। ଅନ୍ୟର Device ରେ କାମ ସରିଲେ Sign out କରନ୍ତୁ।
  • Action ନେବା ପୂର୍ବରୁ Shop, Customer, Order କିମ୍ବା Payment ଠିକ୍ କି ନାହିଁ ଯାଞ୍ଚ କରନ୍ତୁ।
  • Password, OTP, QR Code, Setup Key, Service-role Key କିମ୍ବା Payment Secret କାହାକୁ ଦିଅନ୍ତୁ ନାହିଁ।
  • କୌଣସି Error ଆସିଲେ Security Policy ବନ୍ଦ କରି କିମ୍ବା Payment/Approval ନିୟମ ଉଲ୍ଲଂଘନ କରି ସମାଧାନ କରନ୍ତୁ ନାହିଁ।
  • ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ Shop Status କିମ୍ବା Payment Action ର କାରଣ ଲେଖି ରଖନ୍ତୁ।
ମନେ ରଖନ୍ତୁ: Super Admin ହେଉଛି Platform ନିୟନ୍ତ୍ରଣ ପାଇଁ। ଦୈନିକ Product, Stock ଓ Customer କାମ Shopkeeper ନିଜ Shopkeeper Portal ରେ କରିବେ।

ଏହି ପୁସ୍ତିକା owner.html ରେ ବର୍ତ୍ତମାନ ଥିବା Control ଅନୁସାରେ ତିଆରି। କିଛି ତାଲିକା Read-only। Database ରେ ଥିବା ତଥ୍ୟ ଓ Permission ଅନୁସାରେ ଫଳାଫଳ ମିଳିବ। Button ଦେଖାନଗଲେ କିମ୍ବା Error ଆସିଲେ କାମ ସଫଳ ହୋଇଛି ବୋଲି ଧରନ୍ତୁ ନାହିଁ।
