Product ଖୋଜିବା, Cart, Order, Payment ଓ My Orders କିପରି ବ୍ୟବହାର କରିବେ।

୧. Shop ଓ Product ଖୋଜିବା

  1. Customer Shopping Website କିମ୍ବା Shop ଦେଇଥିବା Store Link ଖୋଲନ୍ତୁ।
  2. Search Box ରେ Product/Service ର ନାମ ଲେଖନ୍ତୁ କିମ୍ବା Category ବାଛନ୍ତୁ।
  3. Product ର Photo, ନାମ, ମୂଲ୍ୟ ଓ ଉପଲବ୍ଧତା ପଢ଼ନ୍ତୁ।
  4. ଦରକାରୀ Product ପାଖରେ Add to Cart ଦବାନ୍ତୁ।
  5. ଏକ Shop ର Product ଅନ୍ୟ Shop ର Product ସହ ମିଶାଇ Order କରିବା ପରିବର୍ତ୍ତେ ପ୍ରତ୍ୟେକ Shop ର ନିଜ Cart/Checkout ଅନୁସରଣ କରନ୍ତୁ।

୨. Customer Account / Profile

  1. Login Button ଦବାଇ Email ଓ Password ଦିଅନ୍ତୁ। Account ନଥିଲେ Signup Option ଥିଲେ ନିଜ ତଥ୍ୟରେ ଖାତା ଖୋଲନ୍ତୁ।
  2. Profile ରେ ନିଜ ନାମ ଓ ଯୋଗାଯୋଗ ତଥ୍ୟ ଠିକ୍ ରଖନ୍ତୁ।
  3. ନିଜ Email/Password ଗୋପନ ରଖନ୍ତୁ। Shared Mobile ରେ କାମ ସରିଲେ Logout କରନ୍ତୁ।

୩. Cart ଯାଞ୍ଚ କରିବା

  1. ଉପରେ ଥିବା Cart Button ଦବାନ୍ତୁ।
  2. Product Name, Quantity ଓ Price ଯାଞ୍ଚ କରନ୍ତୁ।
  3. Quantity ବଦଳାନ୍ତୁ କିମ୍ବା ଦରକାର ନଥିବା Product କାଢ଼ନ୍ତୁ।
  4. Total Amount ଯାଞ୍ଚ କରି Checkout କୁ ଯାଆନ୍ତୁ।

୪. Delivery / Pickup ଓ Order Place

  1. Checkout ରେ ନିଜ ନାମ, Mobile Number ଓ ଠିକଣା ଭରନ୍ତୁ।
  2. Shop ଯେଉଁ Option ଦେଇଛି ସେହି ଅନୁସାରେ Home Delivery କିମ୍ବା Store Pickup ବାଛନ୍ତୁ।
  3. Delivery Pincode, Minimum Order, Delivery Fee ଓ Free Delivery ନିୟମ ପଢ଼ନ୍ତୁ।
  4. Coupon Code ଥିଲେ ଠିକ୍ Code ଦିଅନ୍ତୁ ଏବଂ Discount ଲାଗିଛି କି ଯାଞ୍ଚ କରନ୍ତୁ।
  5. Final Total, Address ଓ Product ପୁଣି ଯାଞ୍ଚ କରି Place Order ଦବାନ୍ତୁ।
  6. Order Confirmation Message/Number ଆସିଲେ ରଖିଦିଅନ୍ତୁ। Confirmation ନଆସିଲେ Order ସଫଳ ବୋଲି ଧରନ୍ତୁ ନାହିଁ।
Shop Delivery ବନ୍ଦ ରଖିଥିଲେ Home Delivery ବାଛିହେବ ନାହିଁ। ଅନ୍ୟ ପିନକୋଡ୍ କିମ୍ବା ଅନ୍ୟ Shop ର ନିୟମ ଲାଗୁ ହୋଇପାରେ।

୫. My Orders ରେ Order ଦେଖିବା

  1. My Orders Button କିମ୍ବା My Orders Page ଖୋଲନ୍ତୁ।
  2. Order କରିବା ସମୟରେ ବ୍ୟବହାର କରିଥିବା ସେହି Customer Account ରେ Login କରନ୍ତୁ।
  3. Order History ରେ Order Status, Items ଓ ଉପଲବ୍ଧ Payment/Delivery Details ଯାଞ୍ଚ କରନ୍ତୁ।
  4. Refresh ଦବାଇ ନୂଆ Status ଦେଖନ୍ତୁ।
  5. Delivered Order ରେ Review Option ଥିଲେ ନିଜ ଅନୁଭବ ଲେଖି Submit କରନ୍ତୁ। Review ପ୍ରକାଶ ପୂର୍ବରୁ Shop ର Approval ଆବଶ୍ୟକ ହୋଇପାରେ।
  6. Order ବିଷୟରେ ସମସ୍ୟା ଥିଲେ Order Number ସହ Shop କୁ ଯୋଗାଯୋଗ କରନ୍ତୁ।

୬. ଗ୍ରାହକଙ୍କ ସୁରକ୍ଷା

  • କାହାକୁ Password, OTP, UPI PIN, Card PIN କିମ୍ବା CVV ଦିଅନ୍ତୁ ନାହିଁ।
  • Payment କେବଳ Website ରେ ଥିବା ଅଧିକୃତ Payment Option ଦ୍ୱାରା କରନ୍ତୁ। ଟଙ୍କା କଟିଗଲେ Order Confirmation ଓ Payment Status ଯାଞ୍ଚ କରନ୍ତୁ।
  • Unknown WhatsApp/Payment Link ରେ ଟଙ୍କା ପଠାନ୍ତୁ ନାହିଁ।
  • ଠିକଣା ଓ Mobile Number ଠିକ୍ ଦିଅନ୍ତୁ, କିନ୍ତୁ ଅନାବଶ୍ୟକ ବ୍ୟକ୍ତିଗତ ତଥ୍ୟ ପଠାନ୍ତୁ ନାହିଁ।
  • Price, Delivery Fee, Return/Refund ଓ Shop Policy Order ପୂର୍ବରୁ ପଢ଼ନ୍ତୁ।
  • ସମସ୍ୟା ହେଲେ Order Number, ସମୟ ଓ ଭୁଲ୍ Message ର Screenshot ଦିଅନ୍ତୁ; Password/OTP/PIN ଲୁଚାଇ ରଖନ୍ତୁ।
Order ପୂର୍ବରୁ ମନେ ରଖନ୍ତୁ: Product → Quantity → Address → Delivery/Pickup → Coupon → Final Total → Place Order।

Website ରେ ଦେଖାଯାଉଥିବା Option Shop ଅନୁଯାୟୀ ଅଲଗା ହୋଇପାରେ। Shop ର ନିୟମ ଓ Payment Confirmation ଯାଞ୍ଚ କରନ୍ତୁ।
